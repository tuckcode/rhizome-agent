## Design Specificity Verdict

**LLM assessment:** Empty Chat is authored for Rhizome. Prime is the named counterpart. The vault is optional context. The dark olive desk is not a generic white LLM page. That specificity drops when the shell fills. The collapsed rail is a standard icon strip. Notes is a capable vault browser that could live in any notes app. Research is a second product with gold CTAs and a six-tab form. Session titles read like leaked prompts. Rhizome’s identity — Chat as the workbench, vault on purpose, Inbox as Notes not mail — is in the architecture, not in the first pixels. A first-timer sees another dark agent chat with a sidebar.

**Deterministic scan:** Detector on `src/App.tsx`, `CommandRail.tsx`, `VaultPanel.tsx`, and `ChatHome.tsx` exited 0 with **zero** findings. The LLM review found the load. The detector did not. No false positives to discard.

**Visual overlays:** No reliable overlay. Cursor browser tabs vanished before inject. `detect.js` never ran in a page. Native `/Applications` screenshots were the visual evidence.

## Overall Impression

The desk is real when work is on screen. A live turn looks like a serious harness. The first empty minute does not. The biggest opportunity is one readable first decision: Ask Prime, with Show Notes as a second labeled control, not six icons and a composer instrument panel.

## What's Working

1. Chat stays the center canvas while Notes is open. The transcript (user bubble, Reasoning, tool use) is clear when there is work.
2. Dark dense language, Phosphor icons, and the Prime green pill feel like a Mac agent desk, not a browser dashboard.
3. Notes is a real vault (Inbox / All Notes / Archive / Projects). Working-tree Browse collapse and a 46px Show Notes strip are the right disclosure instinct. Packaged `/Applications` does not show that strip yet.

## Priority Issues

1. **[P1] Chat vs Inbox identity**
   - **What:** Packaged Inbox click makes Inbox the green destination. Working-tree presses Chat and Inbox together. Rail Tray, Notes “Inbox”, and a hover strip that says “Inbox” are three objects with one word.
   - **Why it matters:** A first-timer cannot tell whether Chat left. Pressed no longer means canvas.
   - **Fix:** One pressed destination for the canvas (Chat). Notes is a panel with Show Notes / Hide Notes. Inbox lives only inside the list.
   - **Suggested command:** `/impeccable distill` then `/impeccable clarify`

2. **[P1] Empty Chat does not teach the first move**
   - **What:** Copy says open a note and does not name a control. Packaged Chat-with-Notes-shut has no Show Notes strip. Source restore is icon-only.
   - **Why it matters:** First message is the product. People stall or click Research.
   - **Fix:** Persistent Show Notes label. Empty-state CTA that names the control. Keep Chat visually primary.
   - **Suggested command:** `/impeccable onboard`

3. **[P1] Composer is an instrument panel before the first ask**
   - **What:** Prime, model, Medium, Agents idle, Skills · rhizome-vault, Goal, Schedule, send/newline, plus Idle · ready and git Δ. Agent and Skills look live and are not.
   - **Why it matters:** The task is “ask Prime.” Configuration owns the foreground.
   - **Fix:** One primary composer. Park model, thinking, and skills behind one control. Wire or remove dead dropdowns.
   - **Suggested command:** `/impeccable distill`

4. **[P1] Open note hides on mouse leave**
   - **What:** `ChatHome` sets `onMouseLeave` to collapse the note pane. Restore is `aria-hidden` and labeled “Inbox”.
   - **Why it matters:** Accidental leave hides the note. Keyboard and VoiceOver cannot recover it. The label lies. Doctrine already says click, not hover.
   - **Fix:** Click to collapse. Strip uses the note title. Focusable, not `aria-hidden`.
   - **Suggested command:** `/impeccable audit`

5. **[P2] Too many columns when Sessions are pinned**
   - **What:** Sessions | Chat | Browse + list. Session rows are truncated prompt dumps. Research does not share Chat’s language.
   - **Why it matters:** Chat becomes the smallest quiet column.
   - **Fix:** Default Sessions collapsed. Keep Browse collapsed. Give Changes a visible Graph split or do not call it Changes.
   - **Suggested command:** `/impeccable layout`

## Persona Red Flags

**Alex (Power User):** Hover-expand rail at 150ms fights precision. Pin sidebar sits next to Settings, not by Chat. Escape vs Stop is the opposite of other agent apps. Agent pill cannot change agent. Skills pill cannot change skills. Session titles are unskimmable.

**Jordan (First-Timer):** Collapsed Chat / Inbox / Research / Changes / Settings / Pin are icon-only. Empty copy does not point at Inbox. Inbox looks like mail. `rhizome-vault` looks like the vault. Goal and Schedule appear with no explanation.

**Sam (Accessibility):** Show Notes is icon-only. Rail badges announce a number, not a name. Note restore is `aria-hidden`. Hover expand/collapse has no keyboard path. Dual `aria-pressed` on Chat and Inbox announces two destinations. Settings stays `expanded={false}` on a pinned rail, so the gear never gets a visible word.

## Minor Observations

- Traffic lights still crowd collapsed Chat.
- `↵ send · ⇧↵ newline` is correct and easy to miss.
- On top / Beside is on the note header. It is invisible until a note is open.
- Inbox cards stack title, model metadata, dates, and type glyphs at similar weight.
- Status “Idle · ready” and composer “Agents idle” repeat one fact.
- Research “Generate → Rhizome Vault” is the most branded control and lives off the main path.

## Questions to Consider

- If this is a Chat-centered desk, why can hover, Escape, and a second pressed icon move the work offstage without asking?

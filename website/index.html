A harness that doesn't forget.

A macOS chat app built around Prime Agent. The built-in vault is your memory, wiki, and second brain. What you save stays as plain Markdown on your disk, where you and the agent can both read it.

View on GitHub Run it locally

20-second demo

What it does

Bring your own model

Prime Agent runs the chat: sessions, tools, skills, and provider login. Pick the model you want.

A vault you own

Notes are plain Markdown in a local folder. No database, no lock-in. Open them in any editor.

Notes beside the chat

Open a note next to the conversation, keep what matters, and let the agent read your vault through MCP.

Research panel

Look things up and bring findings into your notes without leaving the app.

Run it

Developer preview for macOS. You need Node ^20.19.0 or >=22.12.0, pnpm, Rust, and the Tauri toolchain. Prime Agent is installed separately, and there is no signed download yet.

npm i -g prime-agent && prime-agent
git clone https://github.com/tuckcode/rhizome-agent && cd rhizome-agent
pnpm install && pnpm tauri dev

Setup, scope, and recovery: PUBLIC-PREVIEW.md.

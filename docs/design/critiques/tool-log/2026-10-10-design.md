# Tool log note (agent run saved as a note), dark (2026-10-10)

**Who and why:** A developer opening a note an agent wrote ("Grok Wiki Rhizome Vault Analysis") to get the answer. Then, if needed, they check how the agent got there.

- **Sources:** `image-2.png` (Mycelium/dark, about 1024×640pt).
- **Evidence:** `annotated.png`, plus crops `crop-log-dump.png`, `crop-selected-row.png` and `crop-composer.png`.

**Totals:** 1 blocker · 5 worth fixing · 3 minor

## Blocker

**T-B1 · Hierarchy · The note body is a raw terminal log.** It's about 30 lines of "[preparing] … [tool] Grep / [tool] Grep is running. / [tool] Read is running …" set in 13px body Inter, one event per paragraph. The answer, if there is one, is below the fold. The reader came for findings and gets lifecycle noise; "X" and "X is running." doubles every line. *Fix:*
- Store the answer as the note body.
- Collapse the run into one "Run log · 14 tools · 2m 10s" disclosure at the end.
- Inside the disclosure, use JetBrains Mono 12px `--fg-secondary` with one row per tool (name, target, duration, status dot) and no "is running" duplicates.
- Lifecycle steps ([spawned], [grok-auth]…) only appear on failure.

## Worth fixing

**T-W1 · Hierarchy · No title, no answer first.** The body opens with the quoted prompt "→ Asking local/rhizome: …". *Fix:* H1 = the note title. Then a 2–3 line "Answer" summary. The prompt goes in a `--muted` "Asked:" line or in properties.

**T-W2 · Hierarchy · Metadata appears as body text.** "agent: Grok CLI / mode: deep" is in the body. *Fix:* move it to frontmatter, shown in the properties panel (⌘⇧I) or as mono chips under the title.

**T-W3 · Copy · Three agent names on one screen.** The note says Grok CLI, the chat empty state says "Hermes Agent", the composer chip says "Hermes". `image.png` says Claude Code. The user can't tell who will answer. *Fix:* the chat empty state and the composer chip name the same configured agent. Notes show "Written by Grok CLI" as provenance only.

**T-W4 · Color · The selected row is styled with the mint accent.** It has a mint border plus an olive fill. That's a second mint element next to the rail's current icon, and it differs from the light theme. *Fix:* same as V-W4: `--state-selected` + 2px `--accent` left bar.

**T-W5 · Layout · The empty AI Chat panel again takes about 28% of the width.** *Fix:* same as V-W1.

## Minor

- **T-M1:** the block-handle "⋮⋮ +" floats next to log lines because every log event is its own block. *Fix:* T-B1 makes the log one block.
- **T-M2:** the status bar shows "No remote" as a permanent label. *Fix:* show it only while you're in the Changes/History context, or as a `--muted` dot with a tooltip.
- **T-M3:** the breadcrumb says "Note" here, where the light screenshot shows the folder "research". *Fix:* always show the folder path.

# Vault workspace: inbox list + note editor + AI Chat (2026-10-10)

**Who and why:** A developer triaging their vault inbox. They scan recent captures, open one to read or edit, and ask the assistant about it. The list has to make captures easy to tell apart, and the editor has to keep the focus on reading.

- **Sources:** `image.png` (light theme, about 1024×640pt).
- **Evidence:** `annotated.png`, plus crops `crop-inbox-rows.png`, `crop-ai-chat-empty.png`, `crop-composer.png` and `crop-status-bar.png`.
- **Judged against:** DESIGN.md (13px Inter body, mono for technical labels, one mint accent, 4px scale, no sparkle-as-AI).

**Totals:** 0 blockers · 7 worth fixing · 5 minor

## Worth fixing

**V-W1 · Layout · An empty AI Chat panel takes about 29% of the window.** It holds one empty state and a composer, and it squeezes the editor to about 36% (x 340–715pt). *Fix:* collapse the AI panel to its toggle by default and open it with ⌘⇧L or on first use. Once open, cap its default width at 320px.

**V-W2 · Visual design / copy · The empty chat uses the sparkle icon and generic copy.** The sparkle-as-AI glyph is an anti-pattern. "Ask anything to Claude Code" is clumsy, and "Summarize, find connections, expand ideas" is generic. *Fix:* no icon, or the Rhizome mark in `--muted`. Use "Ask Claude Code about this note" plus 2–3 one-tap suggestions built from the open note (e.g. "What links to this?").

**V-W3 · Hierarchy · Each row shows the same date twice.** "July 26, 2026" on the left and "Created July 26, 2026" on the right, in every row. *Fix:* show one date in `--muted`, relative for under 7 days ("3d"), with the full date in the tooltip. The right slot shows the link count or type.

**V-W4 · Interaction and states · The selected row style differs between themes.** Here it's a grey fill plus a 1px border box. In dark (`image-2.png`) it's an olive fill with a mint border. *Fix:* use one style in both: `--state-selected` fill and a 2px `--accent` left bar, no box border.

**V-W5 · Type · Technical labels in the status bar aren't in mono.** "main", "4Δ", "dev" and "Agents idle" are set in Inter. *Fix:* JetBrains Mono 11px for the branch, change count and build. Replace "4Δ" with "4 changed".

**V-W6 · Layout · A column of type icons sits between the rows and the scrollbar.** The coloured file-type glyphs at about x 310pt are crammed against the scrollbar and repeat what the type tells you. *Fix:* move the type to a leading 12px `--muted` glyph before the title, or remove it. Keep 8px between content and the scrollbar.

**V-W7 · Copy · Excerpts show raw agent transcripts.** Rows like "→ Asking local/rhizome: "How does Rhizome's vault…"" show the prompt, not the result. *Fix:* the excerpt is the note's first prose paragraph or summary field. Agent-run notes show their answer's first line.

## Minor

- **V-M1:** the composer chips "Claude ∨ · Power User ∨ · ⚙" don't explain themselves. "Power User" sounds like a permission tier. *Fix:* "Claude Code · Full access" with a tooltip that says what the mode allows.
- **V-M2:** the left rail icons (notes, graph, search, git) have no labels or tooltips in the capture, and the graph icon is the same `ShareNetwork` used for sharing. *Fix:* see app-navigation A-B1.
- **V-M3:** the breadcrumb shows the slug ("karpathy-llm-wiki-pattern"), and five unlabelled icons (☆ ✓ </> ⋯ ▢) sit at equal weight. *Fix:* show the folder › title, keep ☆ and ⋯ only, and move ✓ and </> into ⋯.
- **V-M4:** "Contribute" and "Docs" take permanent status bar space. *Fix:* move them to Help and the ⌘K palette.
- **V-M5:** the editor H1 at about 26px wraps "Pattern" onto its own line at this width. *Fix:* `text-wrap: balance` on note titles.

Developer preview · macOS · open source

Every session leaves notes, not just a transcript.

Rhizome Agent is a desktop agent harness. You chat, the agent works through tools you can see, and what's worth keeping is promoted into Markdown notes in a local, git-backed vault. The next session searches those notes first.

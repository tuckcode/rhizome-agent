**Who and why:** A developer moving between the conversation with Prime and the vault's other views: Research, Graph, Mycelium, Changes and History. They need one place where those views always are, the same name for each view everywhere, and a shortcut once they're fluent.

- **Older build:** the screenshots `image*.png` show an older 4-icon left rail (Notes, Graph, Search, Git). In the current code, `CommandRail` holds sessions and a Settings gear only ("Research opens from the status bar and command palette").

## Findings

### Blocker
**A-B1 · Hierarchy · Peer tools have no home.** Research, Graph, Mycelium, Changes and History are spread over 7 surfaces: note-list header, status bar, sidebar nav, composer + menu, two context menus, and the Connections tabs. Each has a different subset, and none of them is always visible:
- The header group only exists in Notes layouts and collapses into "More list actions" at narrow widths.
- The status bar Graph badge disappears when the command rail is on.
- Mycelium has no ⌘K or menu entry at all.

Someone in the Chat layout (⌘1) can only reach Graph through ⌘K, and Mycelium through the subhead (and only for the current run).

*Fix:* one "Views" group in the left rail, always present (see the recommendation below).

### Worth fixing
- **A-W1 · Hierarchy · The note-list header mixes navigation and settings.** "Workspace shortcuts" in `NoteListHeader` holds three destinations plus a Settings gear in 2nd position, inside a list header whose job is sort and columns. The order (Research, Settings, Mycelium, Graph) matches nothing else. *Fix:* remove the group. Sort and columns stay in the header.
- **A-W2 · Copy · One feature, several names.** Graph has 4 names (Wiki Graph, Graph, Node map, Exit graph), Mycelium 3 (Mycelium, View in Mycelium, Mycelium report), Changes 2 commands. *Fix:* one noun per tool, used everywhere: **Research · Graph · Mycelium · Changes · History**. Contextual verbs: "Show in Graph", "Show in Mycelium".
- **A-W3 · Hierarchy · The status bar mixes status and navigation.** It carries Changes, History, Graph, Research, Contribute and Docs buttons, and its contents change with pill mode. *Fix:* the status bar shows state only (vault, branch, change count, sync, agents). A count may link to its view (the "4 changed" → Changes link is fine), but no bare destination buttons.
- **A-W4 · Interaction · No keyboard path for tools.** None of the five tools has a shortcut. Research is filed under "Settings" in ⌘K. The Go menu has Changes but not Graph, Research, Mycelium or History. *Fix:* a shortcut for each, shown in the rail tooltips, the Go menu and ⌘K.
- **A-W5 · Interaction · Two context actions ignore their context.** Session → "Node map" opens the full graph, and Note → "Mycelium report" opens Mycelium without the note. *Fix:* pass the path (`dispatchNotesChrome('graph', session.path)` / `openConnections('mycelium', entry.path)`), or remove the items.
- **A-W6 · Hierarchy · The composer + menu mixes input with navigation.** It holds "Attach image" next to "View in Mycelium" and "Research". *Fix:* the + menu only adds things to the message (attach, mention a note, skills). The Mycelium link for the current run already lives in the subhead.
- **A-W7 · Visual design · Icons misread.** Research = Sparkle, a DS anti-pattern also used for the AI chat empty state. Graph = ShareNetwork, which reads as "share". *Fix:* Research → MagnifyingGlassPlus or Books. Graph → Graph (Phosphor `Graph`). Mycelium → CirclesThree is fine. Changes → GitDiff. History → ClockCounterClockwise.
- **A-W8 · Interaction · Peer tools open in different containers with the same exit copy.** Graph and Mycelium are tabs in a Connections overlay. Research replaces the chat. Changes and History swap the note list. All three exits read "Back to chat", including when you came from Notes. *Fix:* every tool opens in the main area and the rail shows it as current. Leaving = picking another rail item, ⌘[ (Go Back), or Esc to the previous view, with "← {origin}" naming where you came from.
- **A-W9 · Hierarchy · Changes sits among note filters.** In `SidebarTopNav` it's a git view next to Inbox, All notes and Archive, with no count, and its label is hard-coded English. *Fix:* move it to the rail Views group, where the badge shows the change count. The sidebar keeps the note filters only.

### Minor
- **A-M1:** Settings appears 5 ways, and two gears are on screen at once (rail footer + header group). *Fix:* the rail footer only (plus the menu and ⌘,).
- **A-M2:** "Contribute" and "Docs" take status bar space. *Fix:* Help menu + ⌘K.
- **A-M3:** with Settings placement "off" for Graph or Mycelium, the entry points stay and lead to an "Enable Graph" prompt. *Fix:* hide the rail item when off, or keep the prompt but grey the item out with a tooltip.
- **A-M4:** the View menu orders ⌘1 Chat, ⌘2 Notes, ⌘4 Read, ⌘3 Workbench. *Fix:* re-key it so the menu order is 1–4.

## Recommended grouping

**Principle:** one primary home (the rail), one secondary path (⌘K and the Go menu, same names, same shortcuts), and contextual entries only when they carry context (a note or a session).

Shipped 2026-10-11: four Views with Ctrl+Cmd+1–4 (Mac) / Ctrl+Shift+1–4
(Windows/Linux). Changes sits next to Notes.

```
┌── Rail (collapsed 44px / expanded 200px) ──┐
│  [≡] Rhizome                     (toggle)  │
│  ── Sessions ─────────────────────────────  │
│  + New chat                                │
│  • Promote vs auto-distill   14:08         │
│  • …                                       │
│  ── Views ────────────────────────────────  │
│  ◎  Research                    Ctrl+Cmd+1 │
│  ⌗  Graph                       Ctrl+Cmd+2 │
│  ⁂  Mycelium                    Ctrl+Cmd+3 │
│  ⟲  History                     Ctrl+Cmd+4 │
│                                            │
│  ⚙  Settings                       ⌘,      │
└────────────────────────────────────────────┘
 Status bar (state only): ● Laputa · main · 4 changed · Synced 2m · Agents idle
```

- **Order:** fixed and identical in the rail, the Go menu and ⌘K: Research → Graph → Mycelium → History. This runs from "make knowledge" to "see knowledge" to "see what the agent did". Changes sits next to Notes.
- **Collapsed rail:** icons only, with a tooltip of label + shortcut. The current item gets a `--state-selected` fill + 2px `--accent` bar (the only mint in the rail). Changes shows its count as a `--muted` badge (not mint).
- **Shortcuts (shipped):** Ctrl+Cmd+1–4 on Mac and Ctrl+Shift+1–4 on Windows/Linux. Views are Research, Graph, Mycelium, History. Changes sits next to Notes. ⌘1–4 stay as layouts, ⌘N stays New Note. List them in the ⌘/ sheet.
- **⌘K / Go menu:** "Go to Research / Graph / Mycelium / Changes / History" under one "Views" group. Remove "View Pending Changes" (duplicate) and move "Open Research" out of Settings.
- **Stays contextual** (it carries context):
  - Note right-click → "Show in Graph" (centred on the note).
  - Session right-click → "Show in Mycelium" (that session).
  - Chat subhead footprint icon → "Show in Mycelium" (this run).
  - Status bar "4 changed" → Changes.
  - The Agents pill opens its own activity popover.
- **Removed:**
  - The `NotesChromeShortcuts` group, and its copy in the header overflow.
  - Status bar Research, Graph, History, Contribute and Docs.
  - Composer + menu Research and Mycelium.
  - Sidebar "Changes".
  - Session right-click "Node map".
  - Note right-click "Mycelium report" (unless it gets a note-scoped report).
  - The header and status-bar Settings gears.

**Entry points after the change:** Research 3 (rail, ⌘K, Go menu), Graph 4 (+ note context menu), Mycelium 5 (+ session context menu, subhead), Changes 4 (+ status count), History 3. Every one is reachable with one shortcut from any layout.

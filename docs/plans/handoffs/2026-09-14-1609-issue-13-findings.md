**Origin:** Composer (Cursor) · 2026-09-14 · read-only; no product code

## Plain answer

Running sessions already show in **two** menu-bar surfaces that share one roster read (`list_running_sessions` / `list_prime_running_sessions`). The **Quick Note popover** matches most of #13's acceptance criteria (capture first, activity line, subagent count, click-to-open, quiet empty). The **native tray dropdown** lists running sessions too, but only as **title rows** — no activity subtitle, no subagent count — plus a tooltip count and a disabled "No sessions running" placeholder. **#52's leftover** is not another running list; it is the **finish signal** when a session drops off that roster (ephemeral `Done: {title}` row + short TTL) — not built.

## What already shows running sessions

### Shared roster

| Layer | Path | Role |
|---|---|---|
| Rust host | `src-tauri/src/prime_session_host.rs` → `list_running_sessions()` | Single-flight poll of Prime daemon `list` |
| Tauri command | `src-tauri/src/commands/ai.rs` → `list_prime_running_sessions` | IPC for webviews |
| Pure shaping (TS) | `src/lib/primeRunningSessions.ts` | `toRunningSessionRows`, activity, subagent counts |
| Pure shaping (Rust) | `src-tauri/src/menu_bar_companion.rs` | `running_session_rows`, `session_title` — **simplified mirror**, no activity/subagent fields |

No push event for roster changes; both surfaces poll.

### Surface A — Native tray menu (always reachable)

**File:** `src-tauri/src/menu_bar_companion.rs`

| Behavior | Detail |
|---|---|
| Placement | Running rows **above** capture Area/Screen/Window, then Quick Note / Open / Quit |
| Row content | **Title only** (`session_title`: sessionName → firstMessage → cwd folder → handle) |
| Activity | **Not shown** on tray rows |
| Subagents | **Excluded** from rows (`is_subagent` filter); **count not shown** |
| Empty | Disabled item `"No sessions running"` (`NO_SESSIONS_ITEM_ID`) |
| Cap | 5 rows (`TRAY_SESSION_ROW_LIMIT`); tooltip uses full count via `count_running_top_level_sessions` |
| Poll | Background thread, **15s** (`TRAY_REFRESH_INTERVAL`) |
| Tooltip | `Rhizome` / `Rhizome — 1 session running` / `Rhizome — N sessions running` |
| Click | `session::<id>` → `open_session` → focus main + emit `menu-bar-open-session` with `sessionFile` |
| Tests | `tray_tooltip_*`, `running_session_rows_*`, `session_title_*` in same file |

Module doc explicitly tags this as **#52 job 1 / #13** and notes the tray mirror is deliberately thinner than `primeRunningSessions.ts`.

### Surface B — Quick Note popover webview (Quick Note… / capture UI)

**Files:** `src/components/MenuBarCompanionApp.tsx`, `src/hooks/useMenuBarRunningSessions.ts`

| Behavior | Detail |
|---|---|
| Capture | **First** — autofocus input at top (`menuBarCompanion.capturePlaceholder`) |
| Running section | Rendered only when `running.rows.length > 0` (section omitted when idle — quiet) |

This surface is the full #13 roster UX; tests in `MenuBarCompanionApp.test.tsx`, `useMenuBarRunningSessions.test.ts`, `primeRunningSessions.test.ts`.

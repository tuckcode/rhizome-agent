# C47 — client-owned Prime sessions

The three local Sunday commits ahead of origin are still unrelated leftovers.

## What landed

- Create sends `lifecycle: "client_owned"` and attach advertises
  `client_owned_sessions`.
- `promote_owned_session` / `complete_owned_session` with capability-aware
  errors (refuse before sending if hello omitted the cap).
- `settle_session(Detach | Stop | KeepWorking)`:
  - idle close → detach
  - stop → `complete_owned_session` (kill only as last resort)
  - keep working → promote then detach
- Window close: idle detaches + hides; streaming emits
  `prime-active-close-requested` and the renderer asks.
- Quit uses ownership, not `keep_sessions_running_on_quit`. Toggle removed
  from Settings. Field still parses.

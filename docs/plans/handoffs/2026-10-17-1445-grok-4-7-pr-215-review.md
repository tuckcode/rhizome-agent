# PR #215 review hold — 2026-10-17

**Origin:** Cursor Grok 4.7 · 2026-10-17 · Ricky and Critiquito at `ec0dd1a5`.

## What changed

The branch is rebased onto `8df27d4c`. `parseLibraryScan` is unchanged.
PR #208 was not touched.

The notes sheet offset is `--notes-sheet-offset`, owned by
`useNotesSheetOffset`. It measures the content band when one is on
screen, otherwise the chrome band, otherwise `MACOS_TITLEBAR_HEIGHT`
(32) on native mac. Unmount removes the property. Title bands still
read `--overlay-titlebar-height` for their own min-height, and nothing
writes that variable, so a wrapped subhead can shrink. The overlay
sheet is a flex column so the list fills the box under the band.

Duplicate Mycelium titles append the relative time from `mtimeMs`
(`Untitled session · 2h ago`). Clipping uses grapheme clusters.
A focused session that is not in the list shows its filename. The
overview subtitle says Prime sessions. Native sessions are not added
here.

The settings footer reads `Open settings ⌘,`. Status-bar shortcut
labels are computed when the bar renders. The inbox property picker
comment notes that App passes `inboxPeriod: 'all'`.

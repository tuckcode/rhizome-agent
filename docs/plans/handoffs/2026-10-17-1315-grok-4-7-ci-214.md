# PR 214 CI

**Origin:** Cursor Grok 4.7 · 2026-10-17 · CI on `1777cdec`.

## What changed

- The extended-attribute failure test uses a name both macOS and Linux
  reject, and checks that the rejection happened before asserting the
  file was kept.
- Keychain and legacy log lines no longer include an account or provider id.
- A legacy read or parse error is matched by type. A failed rewrite is
  still returned to the caller.
- A session save that fails without poisoning the writer logs the
  underlying error.

## Left for later

Deleting a key while the legacy file cannot be read returns success
and leaves the file. A later read can copy that key back into the
keychain.

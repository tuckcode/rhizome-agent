## What landed

App-only follow-up to the critiques plan after #140 (`da187dc`) merged.
No Earth theme. No graph, navigation, or website work.

1. **B1** — Transcript is `role="log"` `aria-live="polite"`. One empty
   `role="status"` (`ChatRunLiveStatus`) announces tool start/finish,
   response complete, and stop. Streaming messages set `aria-busy`.
2. **B2 / B3** — Light and dark `--text-muted` and `--text-faint` now
   match `--text-tertiary` so leftover text on those tokens meets 4.5:1.
   Composer placeholder uses `--text-muted`.
3. **B4** — Light `--ok-text` / `--danger-text` / `--warn-text` and
   feedback text tokens point at them. Fills stay on the accent colors.
4. **B5 / W1 / W2** — Model chip is a button named `Model: …` with
   `aria-haspopup="listbox"` and a 2px accent focus ring. Composer stays
   contenteditable while a turn runs; unreadiness still disables it.

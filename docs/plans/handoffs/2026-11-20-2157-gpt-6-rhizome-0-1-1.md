# Rhizome 0.1.1

The first-run sign-in actions sit under the ChatGPT and Claude tiles. Notes
shows direct Auto, Rail, and Open choices. A note preview uses the same fitted
width as the note editor and stacks in a narrow window. Closing the note
restores the saved Sessions rail. The new chat headline scales with the
conversation width.

A native model writes a title after the first successful exchange. A local
title covers Claude Code and unavailable model replies. Manual names take
priority. `native_session_title_generated` tracks titles shown in the active
chat. The event carries no conversation text. This branch includes the
ADR-0191 proposal and its build plan.

The macOS build packages Paper for light and Evergreen for dark. It includes
the Evergreen fallback for older macOS versions. Xcode exported both
appearances, and the compiled catalog contains both layer combinations.

0.1.1 app rendered that graph. Rail and Open each responded to one click in
the installed app. The 0.1.0 bundle has a local backup. Claude Code reported
an existing login. Fresh browser sign-in and a live Dock appearance change
still need a native check.

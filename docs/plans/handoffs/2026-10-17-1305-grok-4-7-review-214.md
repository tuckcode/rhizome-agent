# PR 214 review fixes

**Origin:** Cursor Grok 4.7 · 2026-10-17 · review of `7512a32b`, rebased onto `8df27d4c`.

## What changed

- A failed truncate, rewind, or sync after a short log write returns
  the error and poisons the writer. Later appends return Io. A
  successful repair calls `sync_all`.
- A previous keychain entry that cannot be read no longer blocks a
  save. The generation is bumped again after a restore. An unconfirmed
  restore says the keychain may hold the new key or the old one.
- Legacy file errors are logged once per provider. The long-path
  atomic test accepts a not-found result on Windows.
